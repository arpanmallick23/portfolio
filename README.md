This is the source code of my personal portfolio — a single place to showcase who I am, what I've built, and how I think as an engineer.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- npm (comes with Node.js) or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/arpanmallick23/portfolio.git

# 2. Move into the project folder
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`, or `http://localhost:3000` for Create React App).

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server with hot reload |
| `npm run build` | Create an optimized production build |
| `npm run preview` | Preview the production build locally |

> If the project uses Create React App, replace `dev` with `start`.

## Deployment

The site can be deployed for free on any static host:

- **Vercel** — import the repo and deploy; settings are detected automatically
- **Netlify** — build command `npm run build`, publish directory `dist` (or `build`)
- **GitHub Pages** — push the build output to the `gh-pages` branch

3. Update the meta tags in `index.html`
