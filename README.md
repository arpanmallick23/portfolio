## Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/arpanmallick23/portfolio.git
```

**2. Navigate to the project**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Create a production build**

```bash
npm run build
```
